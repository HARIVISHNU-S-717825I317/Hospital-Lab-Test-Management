# Hospital Lab Test Management

Java console application (23CSR306 Java Programming, Assignment II, Specification 20).

## Problem Statement
Design and implement a Java console application for a Hospital Lab Test Management system that handles patients, tests, orders, samples, results, and billing, with traceability from order to result.

## Classes
Patient, LabTest, TestOrder, TestOrderItem, Sample, TestResult, Invoice, HospitalLabApp (main)

## How to Compile and Run
```
javac *.java
java HospitalLabApp
```
Or import the files into an Eclipse Java project and run HospitalLabApp as a Java Application.

## Menu
1. Add Patient 2. Add Lab Test 3. Create Test Order 4. Collect Sample 5. Record Result 6. Generate Invoice 7. Record Payment 8. Display Orders 9. Exit
